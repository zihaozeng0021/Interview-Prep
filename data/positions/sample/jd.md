### AI Agent Development · Sample（虚构演示）

本岗位由通用的 AI Agent 开发任务推演而来，仅用于展示网站功能，不对应真实公司或招聘信息，也不是完整的面试复习路线。

**演示职责**

- 把自然语言需求拆成可验证的输入、工具操作与完成条件。
- 为工具设计清晰的参数和结果契约，处理超时、重试与重复调用。
- 从文档中检索可定位的证据，用小型评估集检查回答和执行效果。

**演示要求**

- 理解结构化数据与基础 API 调用。
- 了解检索增强生成（Retrieval-Augmented Generation，RAG）的基本流程。
- 能区分检索、生成和工具执行环节的问题，进行简单回归评估。

**如何生成自己的题库**

请使用 coding agent 打开本项目，让它先读取根目录的 `AGENTS.md`，再提供自己的岗位 JD、面试级别和侧重点。`AGENTS.md` 会指导 agent 规划页面、生成知识点和题目、检查覆盖与文件格式。生成完成后刷新网站即可。

Sample 可以用于体验作答记录、错题复习与笔记；这些使用记录只保存在本地，不随演示内容上传。个人岗位请使用其他岗位 id，不要把私人内容填入公开的 `sample` 目录。
